# 世界知识 · 学习备忘录

想了解世界，不一定要先写出一整本百科全书。

这个项目先把知识整理成目录：找到感兴趣的小主题，和 AI 一起学习，记下笔记、勾选进度。

- 浏览、搜索 8,335 个目录条目，也可以随机换一个主题。
- 一键复制主题和教学提示词，交给你常用的 AI。
- 也可以连接自己的 API，在主题下面直接聊天、停止回复、恢复对话和整理笔记。
- 记录完成度、知识点和聊天笔记，支持文件导入与备份。
- 适合手机使用，可添加到桌面；免登录，数据保存在本机。

目录会继续补充，不代表已经覆盖所有知识。图片与附件目前保存说明或引用，不会自动备份原文件。

## 运行

需要 Node.js 22.13 或以上版本。

```bash
npm ci
npm run dev
```

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

开发和预览都带有 AI 接口。正式运行内置聊天：

```bash
npm run build
npm start
```

访问 `http://localhost:3000`，打开一个主题 → **AI 对话** → **连接 AI**，填写 API 地址、模型名称和 Key。首次发送时才验证服务商授权并产生模型用量。

构建结果在 `dist/`。纯静态部署可使用目录、复制、笔记和进度功能；内置聊天需要上述 Node.js 服务端。手机安装与剪贴板功能需要 HTTPS，或在本机 localhost 测试。

## AI 连接

默认启用 `https://api.openai.com/v1`。使用其他 OpenAI Chat Completions 兼容服务时，部署者需把完整 API 基础地址加入 `AI_ALLOWED_BASE_URLS`（逗号分隔），用户再在连接设置里选择相同地址并填写模型名。

公开部署需设置 `APP_ORIGIN=https://你的域名`，在前面配置 HTTPS 反向代理；按环境需要设置 `HOST=0.0.0.0` 和 `PORT`。Node.js 服务只适合单实例，临时连接不在多个实例间共享；不适用于静态 GitHub Pages 或 Cloudflare Workers 直接运行。

- Key 仅保存在服务端内存，最长 2 小时。断开、到期或服务重启后清除；浏览器只有 HttpOnly 会话 Cookie。不要在不信任的部署上配置 Key。
- Key 不写入磁盘、数据库、浏览器存储或应用日志，也不进入备份。部署者仍需避免代理、监控与请求日志记录请求正文或凭据。
- 只发送当前主题与本次对话；个人笔记需主动勾选，最多附带前 8,000 字。长对话只发送最近的上下文，并显示截断提示。
- 这是文字 API 聊天，没有网页检索、图片生成、附件读取或代码执行工具。兼容接口需支持 SSE 流式文本；部分服务商和模型的参数差异可能需要适配。
- 显示服务商返回的 tokens；可手填单价估算聊天费用。中断请求可能不返回用量，整理笔记也会调用 API，实际费用以服务商账单为准。
- API 地址采用部署者允许列表，并检查、固定公开 DNS 地址；不跟随上游重定向。每个连接一次只生成一条回复，有请求长度、时间与频率限制。

部署细节和验证范围见 [docs/v0.2.md](docs/v0.2.md)。

## 数据

目录与笔记功能不需要 API 密钥。只有主动开启 AI 并发送消息时，选中的上下文才经本站服务端发送给指定服务商；请按服务商政策判断数据使用方式。

学习记录与对话保存在本机。换设备或清理浏览器前，请先在设置里导出完整备份。第二版备份包括站内对话，仍可导入第一版备份；导入不会覆盖已有记录。

目录数据在 `lib/catalogue-data.json`。条目使用固定编号，改名不会影响学习记录。

界面基于 React、Vite 和 shadcn/ui。第三方声明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
