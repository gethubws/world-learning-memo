# 第二版：主题内 AI 学习

找到一个主题，和自己的 AI 讨论，再把有用的内容留下来。

## 使用

1. 打开一个主题，选择「AI 对话」。
2. 连接自己的服务：API 基础地址、模型名称、API Key。
3. 输入问题，或使用「帮我找个切入点」。目录是讨论背景，可以自由追问。
4. 对话自动保存；需要归档时选择「整理为笔记」，检查草稿后追加。

停止或断线会保留已经收到的回答。失败后可手动重试；重试保留未完成的回答并追加新回答，可能再次计费。整理为笔记是一次独立的模型请求，确认前的草稿只在当前页面中保留。

学习完成度由使用者决定，AI 不会自动把探索或阅读标记成掌握。

## 运行与部署

Node.js 22.13+；`npm ci`、`npm run build`、`npm start`。

默认监听 `127.0.0.1:3000`。开发模式与预览模式也包含同样的 AI 路由。

| 环境变量               | 用途                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| `APP_ORIGIN`           | 公开部署必填，完整 HTTPS 来源，不含结尾斜杠，如 `https://memo.example` |
| `AI_ALLOWED_BASE_URLS` | 额外允许的完整 HTTPS API 基础地址，逗号分隔；默认已包含 OpenAI         |
| `HOST`                 | 生产服务监听地址，默认 `127.0.0.1`                                     |
| `PORT`                 | 生产服务端口，默认 `3000`                                              |

管理员将 HTTPS 反向代理指向 Node 服务，并关闭 AI 路径的响应缓冲。访问者不用注册应用账户，各自填写 Key。会话密钥只在这个单实例的进程内存中存在；重启或切换实例后需要重新连接。

不要在代理、分析、异常报告或访问日志中记录请求正文、Cookie 或认证信息。API 响应设置为不缓存，Service Worker 排除 `/api/`。

纯静态托管仍能使用原有目录与记录功能，但不会提供聊天后端。现有 Cloudflare Workers 网站不能直接运行这个 Node 版本，需要另行部署或适配会话与网络层。

## 验证范围

自动检查覆盖：本机对话恢复和并发冲突、备份兼容与字段筛选、上下文裁剪、中文流式分块、中断识别、同源与会话检查、Key 到期和清除、服务商错误脱敏、公开地址限制、回复预算、兼容接口参数。

接口测试使用不计费的模拟服务。正式使用前仍需用真实服务商和模型做一次小额度试聊；不保证所有兼容服务支持相同参数。未进行安卓真机验证。
